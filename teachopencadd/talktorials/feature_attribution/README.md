# talktorial-xai

Talktorial on XAI with feature attribution for molecular property prediction.

## Layout

```
src/talktorial_xai/   package code (paths.py holds canonical project paths)
data/raw/             unmodified inputs (git-ignored)
data/processed/       derived datasets (git-ignored)
images/               figures used by the talktorial (tracked)
talktorial.ipynb      talktorial
```

## Setup

```bash
uv sync
```
